# Cyber Panthers Teens - Portal AI

Projeto desenvolvido para competições de robótica educacional.

## Objetivo

Criar uma experiência inspirada no jogo Portal utilizando
inteligência artificial, visão computacional, comunicação entre
robôs e interação humano-robô.

## Principais Tecnologias

- Raspberry Pi 4
- Arduino Mega
- Arduino Uno
- Python
- C++
- MediaPipe
- OpenCV
- Bluetooth HC-05
- LEDs WS2812B
- Motores NEMA 17

## Recursos Desenvolvidos

- Reconhecimento de gestos
- Rastreamento de pessoas
- Sistema GLaDOS em português
- Comunicação robô-robô
- Comunicação robô-humano
- Portais inteligentes com LEDs
- Sistema de transporte de cubos
